# VoiceInvoice Enterprise - Project Purpose

VoiceInvoice Enterprise is a voice-first accounting application designed for a 72h contest. It enables users to create invoices using voice input, leveraging AI (Google Gemini 2.5 Flash + Chirp 3) for transcription and intelligent data extraction.

## Key Goals
- Erstellung von Rechnungen durch Spracheingabe.
- KI-gestützte Transkription und Datenextraktion.
- DSGVO-konforme Anonymisierung (Dual-Layer Privacy Engine).
- TDD-fokussierte Entwicklung mit hoher Testabdeckung.
